# Host Guide

Only the host needs the mod. Players without it can still race and see the splits in chat.

## Starting a 3v3 race

1. Start the game with `ChainedTeams.exe`.
2. Go to **Play** > **Host a Game**, choose **Race mode**, set a password and click **Create Session**.
3. Invite your friends through Steam (up to 6 players).
4. When everyone has joined, type `!balance` in chat to make 3v3 teams. Players can switch with `!team red` or `!team blue`.
5. Press **Play**. The timer starts and split times appear in chat.
6. The first team to reach the top wins. Both teams' times are shown.
7. Type `!rematch` to return everyone to the lobby for another race.

## Practice (1 to 3 players)

1. Start the game with `ChainedTeams.exe` and host a Normal, Beginner or Lava game.
2. At a jump you want to practice, type `!mark <name>`, for example `!mark jump1`.
3. Type `!tp jump1` to teleport your team back to it.
4. For quick retries, use `!save` and `!load`.
5. `!skips` lists your saved positions. They are kept between sessions.

## Troubleshooting

| Problem | Solution |
|---|---|
| Chat says the mod is disabled | The game was updated. Wait for a new version of the mod; the game still works normally. |
| Play button is greyed out | Everyone needs to finish choosing a character. With 5 or 6 players, wait a moment. |
| Teams are uneven | Type `!balance`. |
| Practice commands don't work | They are disabled during a race. |
