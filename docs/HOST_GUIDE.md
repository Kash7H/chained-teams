# 👑 Host guide

You're running the lobby. Here's everything you need.

> 💡 Only the host *needs* the mod. Friends without it can still race and see the splits in chat.
> For the best experience, send everyone the zip anyway.

---

## 🏁 Start a 3v3 race

**1. Open the game with the mod**
Double-click **`ChainedTeams.exe`**.

**2. Create the lobby**
**Play** → **Host a Game** → choose **Race mode** → type a **password** → **Create Session**.

**3. Invite your friends**
Use the normal Steam invite. Up to **6 players**.

**4. Make the teams**
Once everyone's in, press **T** and type **`!balance`**.
You'll get 3 on Red and 3 on Blue. Players can swap with `!team red` / `!team blue`.

**5. Go!**
Press **Play**. The timer starts and each team's split times show up in chat as you climb.

**6. Winner**
The first team to reach the top wins. Everyone sees both teams' times.

**7. Again?**
Type **`!rematch`**. Everyone goes back to the lobby, and nobody has to rejoin.

---

## 🧗 Practice with 1–3 friends

**1.** Open the game with `ChainedTeams.exe` and host **Normal mode** (or Beginner/Lava) as usual.

**2.** At a jump you want to practise, type **`!mark jump1`**.

**3.** Fail it? Type **`!tp jump1`** to get your team straight back there.

**4.** Quick retries: **`!save`** where you are, then **`!load`** to jump back.

**5.** Type **`!skips`** to see all your saved spots. They're remembered for next time.

---

## ❓ Troubleshooting

| Problem | Fix |
|---|---|
| Chat says the mod is "DISABLED" | The game updated. Wait for a new version of the mod. The game still works normally. |
| Play button is greyed out | Everyone needs to finish picking their character. With 5–6 players, wait a second for it to light up. |
| Teams are uneven | Type `!balance`. |
| Practice commands don't work | They're switched off during a live race, so nobody can cheat. |
